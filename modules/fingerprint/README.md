# Модуль fingerprint

Прокидывает отпечаток TLS-клиента в заголовки запроса к апстриму: `X-JA4` и `X-JA3`.
Отпечаток считается один раз на соединение, до TLS; на запрос приходится только
запись двух значений в карту заголовков.

## Подключение

```bash
go build -o bin/xgate ./cmd/xgate
bin/xgate build --src . \
  --with code.sarnas.ru/xgate-modules/fingerprint=./modules/fingerprint \
  --output bin/api-gateway-fp
```

Без модуля шлюз не оборачивает слушатель: на горячем пути ноль работы.

## Конфиг

```yaml
plugins:
  fingerprint:
    enabled: "true"          # false — слушатель не оборачивается
    ja4_header: "X-JA4"      # можно переименовать под свой апстрим
    ja3_header: "X-JA3"
    source_header: "X-FP-Source"
```

## Поведение

- заголовки от клиента **вырезаются всегда**: иначе любой пришлёт свой `X-JA4`;
- `X-FP-Source: gateway` говорит апстриму, кто посчитал отпечаток;
- нет TLS или рукопожатие не разобрано — заголовков нет, апстрим видит «неизвестно»;
- HTTP/3 отпечатка не даёт: QUIC не содержит TLS-записей.

## HTTP/3

Отпечаток снимается с Initial-пакета до quic-go: header protection снимается,
payload расшифровывается, CRYPTO-фреймы собираются (ClientHello может прийти
двумя пакетами). Пакет уходит в QUIC байт в байт — разбор идёт на копии.

Ключи Initial выводятся из DCID и кешируются, иначе на каждый пакет приходится
HKDF с четырьмя расширениями.

## Стоимость

Замер на i5-1235U, `go test -bench .`:

| Режим | Время | Аллокации |
|---|---|---|
| без отпечатка (заголовков нет) | ~12 нс | 0 |
| с отпечатком | ~93 нс | 0 |
| параллельно, 12 потоков | ~60 нс | 0 |

Значения заголовков собираются один раз на соединение и только читаются.
Это проверяется тестом с `-race`: сто горутин одновременно пишут заголовки
из одной структуры соединения.

Рукопожатие TLS стоит порядка 1 мс, то есть отпечаток — доли процента его цены.

HTTP/3, разбор одного Initial-пакета (RFC 9001, A.2):

| Версия | Время | Аллокации |
|---|---|---|
| до оптимизации | 10.8 мкс | 101 |
| с кешем ключей | 6.7 мкс | 52 |
| сборка отпечатков в буфер | 5.1 мкс | **28** |
